# Estudos de PHP Moderno

Este repositório reúne meus primeiros passos, exercícios e desafios práticos em **PHP**, desenvolvidos ao longo do curso de PHP Moderno do professor Gustavo Guanabara (Curso em Vídeo).

> 💡 **Nota sobre o nível de complexidade:** Este espaço é voltado exclusivamente para fins didáticos e fundamentação teórica. Se você deseja avaliar o meu trabalho com projetos complexos do mundo real, recomendo conferir os meus repositórios desenvolvidos em **TypeScript**.

---

## Organização do Repositório

* **Desafios:** Códigos desenvolvidos de forma 100% autônoma para testar a lógica proposta.
* **Exercícios:** Práticas guiadas pelas aulas, muitas vezes estendidas ou modificadas com melhorias pessoais.
